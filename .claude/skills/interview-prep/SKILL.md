name: interview-prep
description: Prep for a specific firm's bar — technical, quantitative, behavioral — and learn from rejections. Use for "prep me for X", "mock interview", or post-rejection debriefs.
---

Read `os/OS.md` and `os/knowledge/identity.md` first. Work only inside `os/`.

1. Read the opportunity record — its "Prep bar" section says what this firm actually tests. Thin? Dispatch the **scout** to research the process (interview structure, question styles, timeline) and write it into the record.
2. Maintain a track file in `os/career/prep/<topic>.md` (mental-math, probability/puzzles, ML, behavioral): current level, target, drill log with dates. Claims of progress require logged drills — never assert an unpracticed skill.
3. Run prep: drills, mock questions at the firm's actual difficulty, behavioral stories grounded in `identity.md` (real experiences only).
4. Rejections are data: debrief into the opportunity's `## Log` (what was tested, where it broke down), distill the durable lesson into `os/memory/semantic.md` territory via the episodic log.
5. Append one episodic entry per session.
6. Session-end ritual per OS.md: uncertainties → `questions.md`, ideas → episodic `idea` line.
