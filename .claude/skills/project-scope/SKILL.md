name: project-scope
description: Capture and scope a project idea — from one-line spark to a build plan. Use for "project idea:", "scope this", "should I build X", or reviving a shelved project.
---

Read `os/OS.md` first. Work only inside `os/`.

1. Create or open the record in `os/projects/` (from `_template.md`).
2. Dispatch the **scout** to research the space: what exists, what's genuinely hard, what's worth building vs. adopting.
3. Scope into the record: what it is, why it matters to Aayush's actual goals (career leverage, recurring annoyance removed, portfolio value), first milestone, next step. Recommend `shelved` honestly when it doesn't earn its time against the pipeline and coursework.
4. If Aayush wants to build now, produce the scaffold/plan in the project's own repo or directory — the OS record tracks status and next steps, not the code.
5. Keep `Next step:` and `Blocked on:` current — the dashboard surfaces blocked projects daily. Log the record, append one episodic entry.
